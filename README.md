NADI PBD v2.6 Analytics — Prototaip Demonstrasi

Cara guna:
1. Buka NADI_PBD_Analytics_v2_6.html dengan Chrome/Edge.
2. Data demo M01–M09 telah dimasukkan berdasarkan Quick Record Formatif 1.
3. Edit/tambah rekod melalui Rekod Baru.
4. Data disimpan dalam localStorage pada komputer tersebut.
5. Gunakan Eksport CSV / Backup JSON untuk salinan.
6. Menu Laporan > Cetak / Simpan PDF untuk laporan ringkas.

Penting:
- Sistem tidak menentukan TP secara automatik.
- Cadangan kluster/intervensi perlu disahkan guru.
- Gunakan kod murid, bukan nama penuh, untuk demo/pembentangan.
